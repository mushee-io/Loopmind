# Mushee LoopMind Premium Demo

This is a static multi-page demo built to deploy easily on Vercel.

## What is inside

- 1 white and orange prelanding page
- 12 white and pink landing routes
- 1 main app shell
- 1 demo grid with 24 interactive demo modules
- analytics, agents, submissions, and main app access pages
- shared design system in `assets/styles.css`
- shared interactions in `assets/app.js`

## Deploying on Vercel

1. Unzip the project.
2. Import the folder into Vercel, or drag and drop it as a static site.
3. No build step is required.
4. The main entry is `index.html`.

## Editing

- Change text inside each HTML file.
- Update the demo list in `assets/app.js`.
- Update the design system in `assets/styles.css`.

## Main routes

- `/index.html` prelanding page
- `/app/index.html` main app shell
- `/app/demos.html` demo suite
- `/app/analytics.html`
- `/app/agents.html`
- `/app/submissions.html`
- `/app/mainnet.html`
- `/landing/...` 12 landing routes
